# IoT-Mini-projets
Ce projet consiste à simuler un feu piéton intelligent permettant de sécuriser la traversée. Lorsqu’un piéton appuie sur un bouton, les feux passent progressivement du vert à l’orange puis au rouge pour les voitures, tandis que le feu piéton devient vert. Un compte à rebours indique le temps restant avant le retour à la situation normale
